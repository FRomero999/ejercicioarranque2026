# Primer proyecto
Este es el primer proyecto de clase
## Aplicación de Tareas
Un pequeño gestor de tareas `Todo-List` por consola. El diseño es a elección del alumno.
#### Historias de Usuario
- Añadir una tareas
- Ver lista de tareas **pendientes**
- Marcar una tarea como completada
- Eliminar una tarea

## Implementación
- Java 27
- `Scanner` y `println` para el UI
- `ArrayList` para la lista de tareas
